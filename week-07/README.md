Midterm reflection

My first idea was a scrapbook portfolio about my journey from Ulaanbaatar to Shanghai to New York. When I started building it, I changed the cities part into sticky notes of things I’ve done, because it says more about me. People said my website felt kind of general, so I added more animations and stickers to make it feel more like me.(Like a diary)

When people visited my site, they couldn’t find my nav bar because it was on the right side. So I moved it, and now my name is in the middle with the links on both sides, so it’s easier to see.
Also they said it might be too empty(my friends said that) so I made the each page take the whole page when scrolling.

I learned that little details are what make a site feel personal. I also learned that one tiny mistake, like a missing }, can break the whole page. And testing on my phone showed me so many problems I didn’t notice on my laptop. Publishing on Github to see it live was also really helpful to share it with more people.

JavaScript experiment

I made a page that changes when you click a button. The first click changes the title and makes the background black, like the story is changing. I also added a second click event on the same button, so the text turns red and says “You were not supposed to find this.” At the end I made the message shake by adding a CSS class with classList.add.

I learned that JS can grab a element like css but do more specific graph things. Like change the text which is complex using css. I also found out that two click events on the same button both run at the same time.
