What did your page teach you when you changed its conditions?

When I made my week 4 page narrow the 3 event columns and the 5 reviews got squished intead of moving together. I learned that shrinking isn't the same as adapting. 

Also giving a div position is really somehow not good when I want my website to be responsive. I tried to put my events in the same position with position but later found out that when I see my website in phone width left: 600 event just disappears. In portfolio, I want to explore options with position. 

A media query lets the layout actually change, like 3 column becoming 1. I also tried a hover where the event picture moves up a little bit which made the cards feel more alive. 

For my portfolio I want to remember that phones can't hover, so I am planning to put the desciptions on the bottom there.
