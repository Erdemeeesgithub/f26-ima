How did my idea change when other people encountered it?

People said my website felt kind of general and that I should try some cool animations. That made sense, since a lot of portfolios look the same and I want mine to feel like me. So I leaned more into the scrapbook idea. Instead of scrolling through 3 cities, I made sticky notes of things I’ve done (Deputy Senator, Admissions Ambassador, Treasurer…) that tilt and straighten when you hover.

A responsive problem I solved: on iPhone width my giant “portfolio” title and the 3 sticky notes didn’t fit. I added a media query to make the title smaller and put the notes in 1 column.

Something that worked differently in the browser: I found a crumpled dot-paper background on Pinterest, but it looked blurry when it stretched across the whole screen. Making it repeat fixed that, but then there was a weird line where the copies met. I had to crop the edges so the dots lined up.
